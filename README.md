# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit that helps users analyze resumes, calculate ATS scores, detect skills, predict resume categories, and generate downloadable reports.

---

## 🚀 Features

- 📄 Upload Resume PDF
- 🧠 NLP-based Skill Detection
- 📊 ATS Score Calculation
- 🎯 Resume Category Prediction
- 💼 Job Role Recommendations
- 🤖 AI Resume Improvement Suggestions
- 📈 Skill Visualization Charts
- 📥 Downloadable PDF Report
- 🌙 Modern Dark UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- SpaCy
- PyPDF2
- Matplotlib
- ReportLab
